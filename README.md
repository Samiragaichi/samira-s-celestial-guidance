# Samira's Celestial Guidance

Crie uma landing page premium, sofisticada e altamente persuasiva para uma taróloga profissional chamada **Taróloga Samira**.

O objetivo principal do site é transformar visitantes em clientes através do WhatsApp, transmitindo credibilidade, acolhimento, espiritualidade e exclusividade.

A identidade visual deve ser inspirada em astrologia, tarot e energia feminina, seguindo exatamente a estética das imagens de referência fornecidas: elegante, delicada, moderna e luxuosa.

## Identidade Visual

Utilize uma paleta composta por:

- Rosa claro (#F7E9EA)
- Rosé (#D8A9B6)
- Nude
- Vinho (#6E3246)
- Bordô
- Dourado metálico (#C9A86B)
- Branco
- Texto em marrom escuro (#3A2B35)

O fundo deve possuir degradês suaves em tons rosé e nude.

Adicionar elementos discretos como:

• Lua crescente
• Constelações
• Estrelas brilhando lentamente
• Cristais transparentes
• Linhas astrológicas delicadas
• Partículas douradas
• Cartas de tarot decorativas
• Brilho sutil

Evite qualquer elemento sombrio, pesado ou assustador.

O design deve lembrar uma marca de luxo.

## Estilo Geral

O resultado final deve parecer um site de alto padrão, sofisticado, moderno e luxuoso.

O design deve transmitir confiança, acolhimento e espiritualidade de forma elegante.

Utilize muito espaço em branco, sombras suaves, cantos arredondados, efeitos premium e uma navegação extremamente fluida.

O visual deve seguir fielmente o estilo das imagens de referência fornecidas, utilizando apenas a estética como inspiração, sem copiar textos ou identidade de terceiros.

O resultado deve impressionar o visitante logo nos primeiros segundos e incentivá-lo a clicar no botão de WhatsApp para agendar sua consulta.
